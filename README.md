# Al-Loloa Restaurant

A simple responsive restaurant website built using **HTML**, **CSS**, and **JavaScript**.

## Features

- Responsive design
- Interactive navigation menu
- Food menu section
- Reservation form
- Ingredients popup modal
- Smooth scrolling
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
